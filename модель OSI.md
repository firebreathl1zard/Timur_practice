Модель OSI (Open Systems Interconnection)

Модель OSI — это эталонная модель, разработанная,
Международной организацией по стандартизации (ISO),
для описания сетевого взаимодействия.
Она определяет, как данные передаются между устройствами в сети,
разделяя процесс на 7 уровней.
Каждый уровень выполняет конкретные функции и взаимодействует только с соседними уровнями.
Модель абстрактна и используется для понимания протоколов (например, TCP/IP соответствует OSI).

Основные характеристики
Цель: Стандартизация сетевых технологий для обеспечения совместимости устройств разных производителей.
7 уровней модели OSI 

Физический: 
Передача битов по среде (кабели, Wi-Fi). Примеры: Ethernet-кабели, сигналы.

Канальный:
Надёжная передача кадров между соседними узлами (MAC-адреса, контроль ошибок). Примеры: Ethernet, PPP.

Сетевой: 
Маршрутизация пакетов между сетями (IP-адреса). Примеры: IP, ICMP.

Транспортный:
End-to-end доставка (надёжная/ненадёжная). Примеры: TCP (надёжный), UDP (быстрый).

Сеансовый:
Управление сеансами (установка/завершение соединений). Примеры: NetBIOS, SIP.

Представительский: 
Преобразование данных (шифрование, сжатие). Примеры: SSL/TLS, JPEG.

Прикладной: 
Интерфейс для приложений. Примеры: HTTP, FTP, SMTP.

Применение
Связь с топологиями: Физический и канальный уровни зависят от топологии сети (например, звезда в Ethernet).
Пример потока: Браузер (уровень 7) → HTTP-запрос → TCP (4) → IP (3) → Ethernet-кадр (2) → Биты по кабелю (1).
