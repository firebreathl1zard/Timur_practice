# Список по команда
1. __ls__ -  утилита Unix, которая печатает в стандартный вывод содержимое каталогов.
2. __nano__ - консольный текстовый редактор 
3. __bash__ - это sh-совместимый интерпретатор командного языка,
выполняющий команды, прочитанные со стандартного входного потока
или из файла. 
4. __man__ - справочник по командам
5. __pwd__ - выводит путь текущего каталога  
6. __passwd__ - изменяет пароль пользователя  
7. __whoami__ - выдает действующий идентификатор пользователя  
8. __date__ - выводит или устанавливает системные дату и время  
9. __timedatectl__ — это командная утилита, которая предоставляет удобный интерфейс для управления временем.
10. __history__ - история использованных команд 
11. __systemstl__ -  это утилита для управления службами и фоновыми процессами
12. __cat__ - утилита в Linux, которая выводит содержание файлов в окне терминала
13. __rm__ -Удаление файлов и директорий
    -__-f__ -Игнорировать несуществующие файлы и аргументы. Никогда не выдавать запросы на подтверждение удаления.
14. __journalctl__ - это команда для просмотра и фильтрации системных журналов в Linux
15. __echo__ — это встроенная команда в системах Unix/Linux, которая позволяет отображать текст или сообщения на экране.
16. df — это утилита в Linux, которая отображает информацию об использовании дискового пространства в файловой системе.
  __-a__, __--all__ — отобразить все файловые системы, в том числе виртуальные, псевдо и недоступные; 
    -__h__ — выводить размеры в читаемом виде, в мегабайтах или гигабайтах; 
    -__H__ — выводить все размеры в гигабайтах; 
    -__i__ — выводить информацию об inode; 
    -__k__ — выводить размеры в килобайтах
17.  __mc__ - это команда для запуска Midnight Commander, текстового файлового менеджера для командной строки
18.  __mv__ - утилита в Linux, которая используется для перемещения или переименования файлов.
19.  __nano__ -  это текстовый редактор командной строки
20.   __whoami__ - команда в Linux, которая выводит имя текущего пользователя, под которым осуществляется работа в систем
21. __timedatectl__ - это командная утилита в Linux, которая позволяет просматривать или изменять настройки даты и времени операционной системы.
