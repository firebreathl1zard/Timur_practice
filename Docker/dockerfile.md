# Dockerfile 
**основные синтаксисы и команды, которые можно использовать в Dockerfile**

**FROM**: Указывает базовый образ, на основе которого будет строиться новый образ.

**LABEL**: Добавляет метаданные к образу.

 **RUN**: Выполняет команды в контейнере во время сборки образа.

 **COPY**: Копирует файлы и директории из контекста сборки в образ.

  **ADD**: Похож на COPY, но может также извлекать архивы и загружать файлы из URL.

  **CMD**: Указывает команду, которая будет выполнена при запуске контейнера. Можно использовать только одну CMD в Dockerfile.

  **ENTRYPOINT**: Определяет команду, которая будет выполнена при запуске контейнера. В отличие от CMD, ENTRYPOINT не может быть переопределен при запуске контейнера.

  **ENV**: Устанавливает переменные окружения.

  **EXPOSE**: Указывает порты, которые будут использоваться контейнером.

  **WORKDIR**: Устанавливает рабочую директорию для последующих команд.

  **VOLUME**: Создает точку монтирования для хранения данных.

  **USER**: Указывает пользователя, от имени которого будут выполняться команды.

  **ARG**: Определяет переменные, которые могут быть переданы во время сборки образа.

  **SHELL**: Изменяет командный интерпретатор, используемый для выполнения команд RUN.
